# Postern visual standard

Version 1 — September 8, 2026.

Applies the shared palette, Bloch sphere mark, sans-serif typography, and refined content spacing to the developer portal. Dark is the initial theme; saved light preferences remain available. Mobile navigation synchronizes aria-expanded, closes on Escape, and resets on desktop widths. JavaScript and CSS syntax checks pass; existing HTML identifiers, action bindings, and external script references are preserved.

The canonical palette and design guidance are in `bloch-sis-pow/docs/site/BRAND-KIT.md` and `docs/site/assets/bloch-tokens.css`. The approved institutional website is maintained in `bloch-sis-pow/apps/site/`.

These source changes retain the existing release process. Production deployment is separate from the design update.
